项目说明

一个自己部署的网站巡检工具：装在 NAS 的 Docker 里，浏览器打开就能用，数据全在自己手里。

它不靠 HTTP 200 判断「网站正常」，而是把页面抓下来看内容像不像一页正常网站——返回 200 的 502、空白页、维护页、跳去别的域名，都会被判为异常。

它记得你网站「原来长什么样」（基线），之后每次巡检对比：文字变了就报「内容变更」，打不开就报「异常」。

D2 详情页右栏 · 同样以高为准、居中留白

项目说明

详情页沿用同一条规则：不裁切、不放大、以高为准。截图最高 520px，宽度按原比例自动收窄并水平居中。

容器宽度内放得下的横图会尽量铺满；方形与竖图则以高度封顶，两侧留白由卡片底色填充。同一套 CSS 兼容所有方向：

img {
  max-width: 100%;
  max-height: 520px;
  width: auto;
  height: auto;
  margin: 0 auto;
}

竖图更长（比如整页长截图 1:4）时不强行完整展示，改成「只显示顶部一屏 + 点击查看原图」。
