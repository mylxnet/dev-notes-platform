## 起因

这个工具处理的是「一人一 Sheet」的卡片式台账——村名、当事人、联系电话、身份证号、纠纷描述，全在单元格里。

要把它公开出去，第一件事不是写 README，是先确认仓库里没有别人的真实信息。于是搜了一遍源码：没有。

然后就差点收工了。问题在于，「源码里没有」和「交付物里没有」是两回事。

## 数据藏在四个地方

逐处翻下来，真实信息分布在四处，只有第一处是代码：

| 位置 | 形态 | 谁在用 |
|---|---|---|
| 源码里的常量 / 默认值 | 字面量 | 程序本身 |
| 演示素材（`--gen-test-files` 生成的一批 xlsx） | 单元格值 | 上手时的示例 |
| 文档与配图 | 示例表格、截图 | 读 README 的人 |
| 界面原型 `prototype/index.html` | 内联的假数据表格 | 看设计稿的人 |
| 冒烟测试断言 | 期望值字符串 | `--smoke-test` |

第二处最容易被漏：演示素材是**程序生成**的，所以「改了代码里的常量」理论上就跟着变了——但已经生成到磁盘上的那一批不会自动更新，仓库里如果提交过，它还是旧的。

第三、第四处是纯文本，人眼扫一遍能看出来，但容易只改一处：README 里的表格改了，`prototype/` 里的 HTML 忘了。

第五处最隐蔽：断言里写着「期望第 3 行内容等于某某某」。数据换了，断言不换，冒烟测试就会红——反过来，如果测试还是绿的，说明**断言没跟上数据的替换**，那才是最坏的情况：所有检查都在说谎。

## 怎么证明它干净

「我改过了」不算证据。能复核的东西才有意义，所以这一轮定的验收物是**解包后的 xlsx**：

xlsx 本质是个 zip，文本内容集中在 `xl/sharedStrings.xml`。真实姓名、手机号这类值一定会在里面留下痕迹。

```
1. 用新构建的 exe 跑 --gen-test-files，重新生成一批演示素材
2. 把生成的 xlsx 解包，取 xl/sharedStrings.xml
3. 搜「应该有的」和「不该有的」
```

实际操作里，第 3 步是两个方向都查：

| 检查 | 期望 | 实测 |
|---|---|---|
| 出现虚构姓名（如「张三」） | 有 | 有 |
| 出现虚构手机号（如 `13800000001`） | 有 | 有 |
| 出现原真实村名 | 无 | 无 |
| 出现原真实姓名 | 无 | 无 |
| 出现真实证件号前缀 | 无 | 无 |

为什么要查「有」也要查「无」？因为只查「无」的时候，如果生成逻辑整个坏掉、生成了一个空文件，检查也会全绿。**正向样本是防止检查本身失效的对照**。

这一步之后，冒烟测试也必须重跑：38 项断言全通过，才说明替换后的数据仍然覆盖了原来那些分支（合并单元格、同名多条、日期类型）。

## 仓库里的那份数据

演示素材能重生成，但有一类东西不能：`test/` 目录里的 UI 自动化脚本，它拉起真实台账跑，断言里写的是真实值。

处理方式是整目录移出仓库，并写进 `.gitignore`：

```
test/
```

代价要说清楚：那份 13 项的 UI 回归记录从此不随仓库分发，只在 `doc/PROJECT_STATE.md` 里留档。下次要重跑，得先用 `--gen-test-files` 现场造一份演示数据，再重写断言。

这里有一个我没解决、也不想含糊带过的问题：**把目录从仓库移出，不等于历史里没有**。之前的提交如果包含过这批文件，`git log` 里还在。真要做到「干净」，得重写历史或者换仓库——这一步这一轮没做，属于明确的遗留项，不能因为「现在 `git status` 是干净的」就当它不存在。

## 顺带的一份产物自检

同一轮还确认了打包产物本身可用：

| 检查 | 结果 |
|---|---|
| 发布产物 `release\台账汇总器-v1.1.6.exe` | 存在，单文件约 71 MB |
| 用该 exe 跑 `--smoke-test` | 退出码 `0` |
| 冒烟断言数 | 38 项全通过、0 失败 |
| 生成素材解包核对 | 通过（见上表） |

用「打包后的 exe」而不是「刚编译出来的 dll」去跑自检，这点是刻意的：自包含单文件发布有自己的坑（路径、嵌入资源、原生库），工程里能跑通不代表发出去的那个文件能跑通。

## 一条判断标准

脱敏这件事，验收物不该是 diff，应该是**产物**。

判断方法可以很土：从真实数据里随手抽三个字段（一个名字、一个号码、一个地名），去交付物里搜。搜得到就是没干净，搜不到才算过——而且要先确认「虚构数据确实能搜到」，否则你搜的是一份空文件。

代码、素材、文档、原型、断言，这五处只要有一处没同步，前面四处都白做。这次最险的一处不是代码，是那句写在冒烟断言里的期望值。
